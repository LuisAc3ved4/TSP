# TSP con Hill Climbing - WebApp

## Requisitos
- Python 3
- Flask: `pip install flask flask-cors`

## Cómo ejecutar

### 1. Levanta el servidor backend
```bash
cd backend
python app.py
```

### 2. Abre el archivo frontend/index.html en tu navegador.

Haz clic en "Calcular Ruta" para ver los resultados del algoritmo.
